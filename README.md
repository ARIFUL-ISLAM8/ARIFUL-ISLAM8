## About Me

As a Computer Science graduate from BRAC University, I thrive at the intersection of full-stack development and applied AI — building real products that solve real problems.

I develop web applications using the MERN stack, Laravel, and Flutter, with a strong focus on clean REST API design, scalable architecture, and collaborative Agile delivery. I've shipped a live production platform serving 250+ active members, and I believe that code only counts when it's deployed and working.

On the AI side, I've integrated the Claude API and OpenAI API into production-ready applications, explored prompt engineering, and I'm actively building knowledge in LangChain, RAG pipelines, vector databases, and HuggingFace — the core stack for the next generation of LLM-powered systems.

Currently open to internship and entry-level roles in **Full-Stack Development**, **Python Development**, **Software Quality Assurance**, and **AI/ML Engineering**. I'm ready to learn fast, ship meaningfully, and grow with a great team.

- ⚡ **Focus**: Full-Stack Development, Python Development, Software Quality Assurance
- 🤖 **Active Learning**: LangChain, RAG Pipelines, Vector Databases, HuggingFace, Embeddings
- 📱 **Also Building**: Cross-platform mobile apps with Flutter & Firebase
- 🤝 **Collaboration**: Open to meaningful projects in AI products, backend systems, or QA
- 💬 **Ask me about**: React, Node.js, Claude API, Python, testing, or Firebase
